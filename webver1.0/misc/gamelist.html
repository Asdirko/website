Game List

I started documenting a list of games that I had beaten about a couple years ago. I'm not entirely sure why I did it other than "preservation." Or whatever. However, I think it helped me engage with the material more, and seeing it on a nicely laid out list prevented it from being mindless consumption. If I played a game and beat it it would go on the list, and it would stay there. Admittantly, I did beat some of these older games with savestate assistance, but recently I've moved away from using emulation tools because I think it dampens the challenge somewhat. Some of these games also don't have a definitive goal, (like racing games, arcade games, etc.) so I just counted "winning" as playing through most of the content in each.
